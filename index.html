Toggle Chatter Everywhere leverages the Show/Hide icon in the ToDo App and makes it available on every Document. Via a System Parameter "toggle_chatter.default_hidden_models" you can list (separated by a comma) models you want to hide the chatter by default. Each user's preference is stored.
